# 🐢 Mini Turtle – Versión Funcional

Este proyecto corresponde a la **versión funcional** del ejercicio *Mini Turtle*.
Se aplican los conceptos de **modularidad** y **empaquetado en Python**.

## 📌 Descripción
La lógica del movimiento de la tortuga se separa de la interfaz pública del
paquete, permitiendo importar las funciones directamente desde el paquete.

## 🧩 Estructura del proyecto
mini_turtle/

├── init.py

└── drawer_logic.py

main.py


## ▶️ Uso
```python
from mini_turtle import adelante, abajo, reiniciar

adelante(5)
abajo()
reiniciar()
```

## 🎯 Conceptos aplicados

•Modularidad

•Paquetes en Python

•Uso de variables globales
